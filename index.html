语法手册 >>> 编者按 <<< 编者按框（四边细线框，蓝色标签，灰色正文14px）
-- 作者 引文署名（写在引用块内单独一行，自动右对齐，-- / — 统一成 ——）
[style:lh=2.2|ls=1px|size=15] 逐处样式覆盖（单独一行，作用于紧随其后的那一块；可用 lh 行距 / ls 字距 / size 字号 / font 字体 / indent 首行缩进 / align 对齐 / mt 上间距 / mb 下间距 / color 颜色）
<u>下划线</u> 下划线（粗体斜体用 Markdown 的 **粗** 和 *斜*）
![book](url) 书籍封面（url可留空，居中，带阴影，188px宽）
[book:封面URL|书名|作者|出版社|年份] 书籍信息（封面URL可留空，居中，灰色12px，封面188px+阴影+▲）
[enbook:封面URL|书名|作者|出版社|年份] 英文书籍信息（封面URL可留空，居中，灰色12px，封面188px+阴影+▲）
[jpbook:封面URL|书名|作者|出版社|年份] 日语书籍信息（封面URL可留空，居中，灰色12px，封面189px+阴影+▲+『』）
正文书籍必填项 作者、出版社、出版年份均不可留空；出版社后必须显示年份
[universal:照片URL|第一行|第二行|...] 通用图片标识（第一行自动加粗，照片+▲+多行文字，用|分行）
[origin:图片URL|第一行|第二行|...] 原图尺寸图片标识（第一行自动加粗，图片按原始尺寸显示，超宽时等比缩小）

## 标题 小标题（居中，#3daad6蓝色加粗，在分割线下方）
^① 脚注编号（蓝色上标）
（外文） 半角括号内自动灰色小字12px
---[notes] 注释区开始（14px黑色标题+细线+240px滚动区）
^[①脚注内容] 注释条目（12px，蓝色编号+灰色文本，编号后不留空格）
^[① ... *English Title* ...] 注释 / 尾注内支持 *斜体* **粗体**（英文书名用斜体）
---[/notes] 注释区结束
---[note] 尾注区开始
- ・ 内容 尾注条目（12px灰色）
---[/note] 尾注区结束
---[bio-title:标题] 作者/译者简介区开始（蓝色标题+分割线）
[bio-img:url] 简介区照片（居中，156px宽）
[bio:文本] 简介区文字（14px灰色）
---[/bio] 简介区结束
---[reading-title:标题] 延伸阅读区开始
[reading-book:书名|编者|译者|图片url] 延伸阅读书籍（图片url可留空，中文书名带《》，译者和图片可省略）
[reading-enbook:书名|编者|出版社|图片url] 延伸阅读英文书籍（图片url可留空，书名斜体，无书名号）
[reading-jpbook:书名|编者|出版社|图片url] 延伸阅读日文书籍（图片url可留空，书名带『』）
---[/reading] 延伸阅读区结束

---[/follow] 关注引导区结束
